# TBOX

C++ 객체지향 프로그래밍을 활용하여 구현한 콘솔 기반 영화관 좌석 예매 및 결제 프로그램입니다.

사용자는 영화관을 선택한 뒤 영화 정보와 좌석 현황을 확인하고 원하는 좌석을 예약할 수 있습니다. 예약 후 발급된 예약 번호를 이용하여 결제를 진행할 수 있으며, 관리자 메뉴에서는 상영관별 매출과 전체 티켓 판매량을 확인할 수 있습니다.

## 주요 기능

### 영화관 선택

다음 세 개의 영화관 중 하나를 선택할 수 있습니다.

- CGV 영화 1관
- 롯데시네마 영화 2관
- 메가박스 영화 3관

### 영화 정보 조회

영화관별로 다음 정보를 확인할 수 있습니다.

- 영화 제목
- 출연 배우
- 영화 줄거리
- 티켓 가격

### 좌석 현황 조회

상영관의 좌석 상태를 표 형태로 확인할 수 있습니다.

| 표시 | 상태 |
| --- | --- |
| `-` | 예약 가능한 좌석 |
| `R` | 예약된 좌석 |
| `$` | 결제가 완료된 좌석 |

### 좌석 예약

- 좌석의 행과 열 번호를 입력하여 예약
- 예약되거나 결제가 완료된 좌석의 중복 예약 방지
- 예약 완료 시 예약 번호 자동 발급
- 예약 번호는 100번부터 순차적으로 증가

### 결제

발급받은 예약 번호를 입력한 뒤 다음 결제 방법 중 하나를 선택할 수 있습니다.

- 모바일 결제
- 은행 이체
- 신용카드 결제

결제가 완료되면 결제 금액과 결제 수단이 해당 좌석 정보에 저장됩니다.

### 관리자 통계

관리자 메뉴에서 다음 정보를 확인할 수 있습니다.

- CGV 상영관 총 결제 금액
- 롯데시네마 상영관 총 결제 금액
- 메가박스 상영관 총 결제 금액
- 전체 티켓 판매량

## 상영관 구성

| 영화관 | 상영 영화 | 티켓 가격 | 좌석 |
| --- | --- | ---: | ---: |
| CGV 영화 1관 | 분노의 질주: 라이드 오어 다이 | 15,000원 | 8 × 8 |
| 롯데시네마 영화 2관 | 스즈메의 문단속 | 12,000원 | 10 × 10 |
| 메가박스 영화 3관 | 노트북 | 20,000원 | 8 × 8 |

## 객체지향 설계

### Screen

상영관의 공통 기능을 관리하는 추상 클래스입니다.

- 영화 제목과 가격 관리
- 좌석 배열 생성 및 제거
- 좌석 현황 출력
- 좌석 예약
- 결제 처리

`CGVScreen`, `LotteCinemaScreen`, `MegaboxScreen` 클래스가 `Screen` 클래스를 상속받습니다. 각 클래스는 영화 정보를 출력하는 함수를 재정의합니다.

### Ticket

좌석 하나에 대한 정보를 저장합니다.

- 좌석 행과 열
- 좌석 상태
- 예약 번호
- 결제 금액
- 결제 수단

### Pay

결제 기능을 정의하는 추상 클래스입니다.

`MobilePay`, `BankTransfer`, `CardPay` 클래스가 `Pay` 클래스를 상속받아 결제 방식별 금액을 계산합니다.

### TUKoreaTBox

프로그램의 전체 흐름과 영화관 객체를 관리합니다.

- 영화관 객체 생성
- 영화관 선택 메뉴
- 관리자 메뉴
- 상영관별 통계 조회

### Statistics

결제가 완료된 좌석을 기준으로 통계를 계산합니다.

- 상영관별 총 결제 금액 계산
- 전체 티켓 판매량 계산

## 실행 방법

1. Visual Studio를 실행합니다.
2. `PYJ_TBOX.sln` 파일을 엽니다.
3. 프로젝트를 빌드합니다.
4. 디버깅을 시작하여 콘솔 프로그램을 실행합니다.
5. 화면에 표시되는 메뉴 번호를 입력하여 기능을 이용합니다.

## 프로젝트를 통해 학습한 내용

- 공통 기능을 부모 클래스로 분리하고 상속 구조를 설계했습니다.
- 순수 가상 함수를 사용하여 추상 클래스를 구현했습니다.
- 자식 클래스에서 함수를 재정의하여 영화관별 정보를 출력했습니다.
- 이중 포인터와 동적 메모리 할당을 이용해 크기가 다른 좌석 배열을 생성했습니다.
- 좌석 예약, 결제, 통계 기능을 클래스로 나누어 각 클래스의 역할을 분리했습니다.
- 생성자와 소멸자를 사용해 동적으로 생성한 객체와 배열을 관리했습니다.
